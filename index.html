Neracaku

Aplikasi pencatat keuangan pribadi yang dipakai hanya oleh pemiliknya sendiri. Tidak untuk umum.

Kebijakan Privasi

Terakhir diperbarui: 12 November 2026.

Data yang diakses

Dengan izin pemilik akun Google, aplikasi memakai akses baca-saja Gmail (gmail.readonly) untuk membaca email notifikasi transaksi dari bank (bca@bca.co.id) agar transaksi tercatat otomatis di buku keuangan pribadi pemilik.

Penggunaan dan penyimpanan

Isi email hanya diurai untuk mengambil tanggal, nominal, dan keterangan transaksi. Data disimpan di server pribadi milik pemilik dan tidak dikirim, dijual, atau dibagikan ke pihak ketiga. Aplikasi tidak mengirim, menghapus, atau mengubah email apa pun.

Penggunaan data Google

Penggunaan informasi yang diterima dari Google API mematuhi Kebijakan Data Pengguna Layanan API Google, termasuk persyaratan Penggunaan Terbatas. Data tidak dipakai untuk iklan maupun pelatihan model AI.

Pencabutan akses

Pemilik dapat mencabut akses kapan saja di myaccount.google.com/permissions.
